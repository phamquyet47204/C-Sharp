# Sơ đồ Sequence Lượt Truy Cập Online Ngắn Gọn

```mermaid
sequenceDiagram
    autonumber
    actor Visitor as Visitor
    participant App as App.xaml.cs
    participant Mobile as AnalyticsService
    participant API as AnalyticsController
    participant UC as AnalyticsVisitUseCase
    participant Repo as AnalyticsRepository
    participant DB as AnalyticsEvents DB
    participant Hub as AnalyticsHub
    actor Admin as Admin UI
    participant RT as realtimeAnalytics.js

    Visitor->>App: Mở app
    App->>App: OnStart() / OnResume()
    App->>Mobile: TrackAppLifecycleAsync("online")
    Mobile->>API: POST /api/analytics/visit (app_online)
    API->>UC: LogVisit() -> ExecuteAsync(command)
    UC->>UC: BuildAnonymousDeviceId()
    UC->>Repo: AddVisitEventAsync(evt)
    Repo->>DB: SaveChangesAsync()
    API->>API: PublishRealtimeUpdateAsync()
    API->>API: BuildRealtimePayloadAsync() + GetOnlineUserCountInternal()
    API->>Hub: SendAsync("analytics:realtime", payload)

    Visitor->>App: Di chuyển / vào POI / nghe narration
    App->>Mobile: TrackActivityAsync(lat, lng, eventType, poiId)
    Mobile->>API: POST /api/analytics/visit
    API->>UC: ExecuteAsync(command)
    UC->>Repo: AddVisitEventAsync(evt)
    Repo->>DB: SaveChangesAsync()
    opt eventType == narration
        API->>DB: Lưu FreeTrialRecord nếu chưa tồn tại
    end
    API->>API: PublishRealtimeUpdateAsync()
    API->>Hub: SendAsync("analytics:realtime", payload)

    Admin->>API: GET /api/analytics/realtime-overview
    API->>API: GetRealtimeOverview()
    API->>DB: Lấy events 45 giây gần nhất
    Note over API: Lọc online nếu event mới nhất mỗi DeviceId<br/>trong 30 giây và != app_offline
    API-->>Admin: { onlineCount, points, total, measuredAt }

    Admin->>RT: startRealtimeAnalytics(onMessage)
    RT->>Hub: Kết nối /hubs/analytics
    Hub->>Hub: OnConnectedAsync() -> AddToGroup("admins")
    Hub-->>RT: analytics:realtime(payload)
    RT-->>Admin: onMessage(payload)
    Admin->>Admin: applyRealtimePayload()

    Visitor->>App: Đóng app / sleep
    App->>App: OnSleep()
    App->>Mobile: TrackAppLifecycleAsync("offline")
    Mobile->>API: POST /api/analytics/visit (app_offline)
    API->>UC: ExecuteAsync(command)
    UC->>Repo: AddVisitEventAsync(evt)
    Repo->>DB: SaveChangesAsync()
    API->>Hub: SendAsync("analytics:realtime", payload)
```

## Phương thức chính trong luồng

- Mobile app: `OnStart()`, `OnResume()`, `OnSleep()`, `TrackAppLifecycleAsync()`, `TrackActivityAsync()`
- Backend API: `LogVisit()`, `GetRealtimeOverview()`, `PublishRealtimeUpdateAsync()`, `BuildRealtimePayloadAsync()`, `GetOnlineUserCountInternal()`
- Application/Repository: `ExecuteAsync()`, `BuildAnonymousDeviceId()`, `AddVisitEventAsync()`
- Realtime admin: `startRealtimeAnalytics()`, `OnConnectedAsync()`, `applyRealtimePayload()`
